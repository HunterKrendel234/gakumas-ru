ПК (DMM)

Локализация для компьютерной версии игры через DMM.
Сложность: Легкая (3 шага).
Если будет трудно - загляните сюда.

Важно! Сохраните прогресс игры перед установкой!

Перед установкой или обновлением локализации сохраните данные игры, чтобы не потерять прогресс:

  1. Чтобы сохранять и переносить прогресс между PC и Android, необходимо привязать игру к Bandai Namco ID.
  2. Зарегистрировать аккаунт можно здесь: bandainamcoid.com
  3. ⚠️ Для работы игры как на ПК, так и на смартфоне требуется японский VPN-сервер.

🔗 Привязка аккаунта в игре

  1. После начала игры и прохождения первых сцен/первого продюсирования откройте главное меню.
  2. Нажмите на иконку с тремя полосками в правой части экрана.
  3. В открывшемся меню выберите Связь данных.

📥 Загрузка сохранения

Если необходимо загрузить уже существующий прогресс на другом устройстве:

  1. На титульном экране игры нажмите Связь данных.
  2. Войдите в тот же Bandai Namco ID, к которому ранее был привязан прогресс.
  3. Следуйте инструкциям на экране для восстановления данных.
  • ⚠️ Не создавайте новую привязку, если хотите загрузить существующее сохранение. Используйте тот же Bandai Namco ID, который был привязан к вашему предыдущему прогрессу.

    • 📦 Шаг 1. Подготовка

    1. ⚠️ Для работы игры как на ПК, так и на смартфоне требуется японский VPN-сервер.
    2. Скачайте DMM_GakumasLocalify_v-.-.-.zip последней версии: Gakumas Localify
    3. Зайдите на DMM Gakumas: DMM Gakumas
    4. ⚠️ Для работы DMM Game Player и игры требуется японский VPN-сервер.
      Его отключение и запуск DMM Game Player приведет к выходу из аккаунта DMM Game Player.
    5. Нажмите Game Start.
    6. Скачайте и установите DMM Game Player выбрав его в качестве средства запуска.
    7. После установки запустите DMM Game Player и зарегистрируйте или войдите в аккаунт.
    8. После найдите Gakumas и установите игру.
    9. После запустите игру.
    10. 💡 Если работает, можно закрыть игру.

    🛠️ Шаг 2. Установка

    1. Откройте скаченный ранее архив DMM_GakumasLocalify_v-.-.-.zip
    2. Скопируйте из архива папку и файл в корень с игрой.
    3. 💡 Папка gakumas-local и файл version.dll
      Путь к игре: C:\Users\%USERPROFILE%\gakumas
    4. Удалите все в папке gakumas-local.

    🌐 Шаг 3. Установка русской локализации

    1. Запустите игру и нажмите Ctrl + U чтобы открыть Gakumas Config GUI.
    2. Раскройте все пункты и выставите параметры как на скриншоте.
    3. 💡 За правый край окна конфигурации можно растянуть окно.
    4. В пункте API Address (Github Latest Release API) замените стандартную ссылку на:
      5. https://api.github.com/repos/HunterKrendel234/Gakumas-Translation-Data-RU/releases/latest
    5. Нажмите Chek.
    6. Скачайте обновление локализации и перезапустите игру.

    🎉 Готово!

    Русская локализация установлена.
    В дальнейшем игру можно запускать обычным способом.
    Через её стандартный значок на рабочем столе.

    Приятной игры!

    Android

    Локализация для Android-устройств.
    Сложность: Средняя (4 шага).
    Если будет трудно - загляните сюда.

    • 📦 Шаг 1. Подготовка

    1. ⚠️ Для работы игры как на ПК, так и на смартфоне требуется японский VPN-сервер.
    2. Скачайте и установите: Shizuku: Shizuku
    3. Скачайте и установите: Gakumas.Localify_v-.-.-.APK последней версии: Gakumas Localify
    4. Скачайте игру в формате XAPK.
    5. 💡 Google Play версию игры можно вытащить через утилиты в нужный формат.
      Этот процесс чуть сложнее, поэтому не будем рассматривать.
      Например, можно найти XAPK игры на APKPure (не реклама): APKPure (не реклама)
    6. ⚠️ Сторонние источники скачивания APK/XAPK (в том числе APKPure) используйте на свой страх и риск.

    🛠️ Шаг 2. Настройка Shizuku

    1. 💡 Необходимо включить режим разработчика на телефоне и запустить Shizuku через отладку по Wi-Fi.
      Это позволит Localify получить необходимые права для патчинга игры.
    2. Включите Режим разработчика в настройках Android.
    3. В меню разработчика активируйте «Отладка по Wi-Fi».
    4. Откройте Shizuku и во вкладке «Запуск через отладку по Wi-Fi» нажмите «Сопряжение».
    5. Прочитайте инструкцию на экране и нажмите «Параметры разработчика».
    6. В настройках отладки по Wi-Fi выберите «Подключить устройство с помощью кода подключения».
    7. Появится код сопряжения. Shizuku отправит уведомление - введите этот код в уведомлении.
    8. Вернитесь на главный экран Shizuku и нажмите «Запустить».
    9. После успешного запуска появится пункт «Доступно для 0 приложений» (или больше). Нажмите на него.
    10. Включите доступ для Gakumas Localify.

    🪄 Шаг 3. Патчинг и установка игры

    1. Откройте Localify.
    2. В Localify перейдите во вкладки Home и Advanced и установите параметры в соответствии со скриншотами.
    3. Нажмите на иконку волшебного карандаша слева.
    4. Убедитесь, что отображается: Shizuku service available.
    5. 💡 Это означает, что Shizuku успешно запущен и доступен для Localify.
    6. Выберите режим Integrated.
    7. Нажмите на волшебный карандаш справа.
    8. Выберите ранее скачанный XAPK-файл игры.
    9. Дождитесь окончания патчинга.
    10. Когда появится: Patch finished. Start installing? нажмите ОК.
    11. После успешной установки в нижней части лога Localify появится: Done
    12. 💡 После установки можно отключить режим разработчика, закрыть Shizuku и удалить исходный XAPK, чтобы освободить место.
    13. ⚠️ Не удаляйте Localify и Shizuku. Они понадобятся для последующих обновлений игры.

    🌐 Шаг 4. Установка русской локализации

    1. В поле со ссылкой на GitHub API сначала нажмите Check, чтобы загрузить базовое обновление локализации.
    2. Полностью закройте Localify (выгрузите приложение из памяти).
    3. Снова откройте Localify.
    4. В пункте API Address (Github Latest Release API) замените стандартную ссылку на:
      5. https://api.github.com/repos/HunterKrendel234/Gakumas-Translation-Data-RU/releases/latest
    5. Нажмите Check и дождитесь загрузки русской локализации.
    6. После завершения загрузки нажмите стрелку справа для первого запуска игры.
    7. 💡 При первом запуске игра может закрыться. Это особенность LSPatch, поэтому просто повторно запустите игру.

    🎉 Готово!

    Русская локализация установлена.

    Через её стандартный значок на рабочем столе.

    О проекте

    Русификация выполнена с использованием автоматизации на базе локальной LLM-модели. Репозиторий основан на английском проекте Gakumas Translation Data EN.

    В связи с автоматизированным переводом в локализации могут встречаться неточности. Например:

    • перепутанный род в фразах персонажей;
    • некорректные формулировки;
    • слитный или неудачно оформленный текст в некоторых карточках;
    • другие ошибки перевода.

    Основная цель проекта - сделать Gakumas понятнее для игроков, которые не знают японский или английский, но любят айдол-тематику, аниме или просто хотят познакомиться с игрой.

    Техническая информация (для переводчиков и помощников)
    • ./local-files/localization.json - строки локализации, в основном UI
    • ./local-files/generic.json - общие строки, в основном UI
    • ./local-files/genericTrans/index - общие строки, в основном UI
    • ./local-files/genericTrans/lyrics - песни
    • ./local-files/resource - ресурсные файлы, в основном комму (сюжетные сцены)
    • ./local-files/gakumasassets - кастомный шрифт для ПК-версии игры
    • ./local-files/gkanz0-ontMIX.otf - кастомный шрифт для Android-версии игры
